# Useful Tools for Space Apps Projects

Choose tools based on the challenge and your team's skills. You do not need to use every tool listed here.

## Collaboration and planning

- [GitHub](https://github.com/) — version control, issues, project discussions, and code collaboration.
- [GitHub Docs](https://docs.github.com/) — guides for repositories, branches, issues, and pull requests.
- [Miro](https://miro.com/) — collaborative whiteboards and brainstorming.
- [Google Docs](https://docs.google.com/) — shared notes and writing.

## Development

- [Visual Studio Code](https://code.visualstudio.com/) — code editor.
- [Git](https://git-scm.com/) — version control.
- [Node.js](https://nodejs.org/) — JavaScript runtime and tooling.
- [Python](https://www.python.org/) — programming language widely used for data work.
- [Jupyter](https://jupyter.org/) — interactive notebooks for exploration and analysis.

## Mapping and geospatial work

- [QGIS](https://qgis.org/) — open-source geographic information system.
- [Leaflet](https://leafletjs.com/) — JavaScript library for interactive maps.
- [CesiumJS](https://cesium.com/platform/cesiumjs/) — 3D geospatial visualization.

## Data analysis and visualization

- [Python pandas](https://pandas.pydata.org/) — tabular data analysis.
- [Matplotlib](https://matplotlib.org/) — plotting and visualization.
- [Observable](https://observablehq.com/) — interactive data exploration and visualization.
- [Plotly](https://plotly.com/) — interactive charts.

## Design and presentation

- [Figma](https://www.figma.com/) — interface design and prototyping.
- [Canva](https://www.canva.com/) — visual design and presentations.

## Choosing tools wisely

1. Start from the problem and data, not from a trendy technology.
2. Prefer tools at least one teammate can use confidently.
3. Check pricing, account requirements, usage limits, and internet needs.
4. Confirm that the tool can handle your data format.
5. Credit external libraries, assets, and services as required.
6. Keep a backup plan for demos and connectivity problems.

This list is community-curated, not an official NASA endorsement. Tool availability and terms can change.

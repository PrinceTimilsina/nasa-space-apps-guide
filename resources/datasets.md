# Finding and Working with Datasets

This page helps you discover data for a Space Apps project. It is a starting point, not a complete catalog.

## Useful places to search

| Resource | What you may find |
|---|---|
| [NASA Open Data](https://data.nasa.gov/) | Catalog records for NASA datasets |
| [NASA Earthdata](https://www.earthdata.nasa.gov/) | Earth observation and Earth science data |
| [NASA Planetary Data System](https://pds.nasa.gov/) | Data from planetary science missions |
| [NASA Image and Video Library](https://images.nasa.gov/) | Searchable NASA images and videos |
| [NASA APIs](https://api.nasa.gov/) | Selected APIs for developers |
| [NASA Science](https://science.nasa.gov/) | Science topics and links to data resources |

## Dataset evaluation checklist

For every dataset you plan to use, record:

- Dataset name and provider
- Official landing page or download URL
- What the data represents
- Collection period and last update
- Geographic or planetary coverage
- Units, coordinate reference system, and file format
- Data quality notes and known limitations
- Access method and any account requirements
- License, terms, and attribution instructions
- Date your team accessed the data

## Common data formats

- **CSV:** tabular rows and columns.
- **JSON:** structured records often returned by APIs.
- **GeoJSON:** geographic features represented as JSON.
- **GeoTIFF:** raster imagery with geographic information.
- **NetCDF / HDF:** scientific data formats often used for multidimensional observations.
- **Images and video:** visual media with associated metadata.

Choose tools that support the format and size of your data. Do not download huge files until you know you need them.

## Keep a data log

A simple spreadsheet can track the datasets your team has inspected, selected, or rejected. This makes it easier to explain your methodology and credit sources accurately.

## Interpret carefully

Data may contain gaps, uncertainty, different resolutions, or measurement limitations. Avoid making claims stronger than the data supports. If you transform, filter, or combine datasets, document what you did.

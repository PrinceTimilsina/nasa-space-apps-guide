# NASA Open Data

NASA makes a wide range of data available for research, education, exploration, and software projects. Data may include satellite observations, planetary science, astronomy, mission information, images, and more.

## Start with these official portals

- [NASA Open Data Portal](https://data.nasa.gov/) — searchable catalog of NASA datasets and metadata.
- [NASA APIs](https://api.nasa.gov/) — catalog and documentation for selected developer-friendly APIs.
- [NASA Earthdata](https://www.earthdata.nasa.gov/) — Earth science data, tools, and documentation.
- [NASA Science data and archives](https://science.nasa.gov/) — science topics and links to mission and discipline resources.
- [NASA Image and Video Library](https://images.nasa.gov/) — search NASA imagery and video.

## How to explore a dataset

1. Start with a question related to your challenge.
2. Search an official catalog using relevant keywords.
3. Read the dataset description and metadata.
4. Check the time range, geographic coverage, units, file format, and update frequency.
5. Read access instructions and usage or attribution requirements.
6. Download a small sample or inspect an API response first.
7. Record the dataset title, provider, URL, access date, and any limitations.

## Check before using data

- Does the data actually measure what your project needs?
- Is the spatial and temporal resolution appropriate?
- Are units and coordinate systems documented?
- Is the data current enough for your use case?
- Are there quality flags, uncertainty estimates, or known limitations?
- Are there attribution or access requirements?

## Important

NASA's open-data portals are catalogs and gateways to many different archives. A catalog entry may describe a dataset while the actual files are hosted elsewhere. Follow the dataset's own documentation and terms.

Never assume that every image, logo, map tile, or third-party dataset on a NASA page is automatically free of all restrictions. Check the specific source and usage guidance.

# 🤝 Contributing to NASA Space Apps Guide

Thank you for your interest in contributing!
We welcome everyone who wants to make this guide more useful for NASA Space Apps Challenge participants.

## How Can You Contribute?

- Improve existing documentation.
- Add useful NASA resources and APIs.
- Share tutorials and learning materials.
- Fix grammatical errors or outdated information.
- Add beginner-friendly explanations.

## Before you contribute

1. Check whether the topic already exists in the guide.
2. Prefer official NASA or relevant space-agency sources for factual claims.
3. Include a source link for important facts, especially dates, rules, data descriptions, and API details.
4. Do not present personal opinions as official NASA requirements.
5. Do not upload private information, API keys, passwords, or copyrighted material without permission.

## How to Contribute

1. Fork this repository.
2. Clone your fork.
3. Create a new branch.
4. Make your changes.
5. Commit your changes.
6. Open a Pull Request.

You can also open an Issue to suggest improvements.

## Guidelines

- Use plain, welcoming language.
- Explain acronyms the first time they appear.
- Use headings and short paragraphs.
- Add descriptive link text rather than writing “click here”.
- Include the date you checked information when it is likely to change.
- Make clear whether something is an official rule, a recommendation, or a personal tip.
- Keep examples inclusive of different skills, backgrounds, and experience levels.


## Pull request checklist

- [ ] My change is relevant and easy to understand.
- [ ] I checked spelling and formatting.
- [ ] I added sources for factual or time-sensitive information.
- [ ] I did not include secrets or private information.
- [ ] I checked that links work.
- [ ] I respected copyright and third-party licenses.

## Community Guidelines

Be respectful, welcoming, and constructive.
Every contribution matters. Thank you for helping make space exploration more accessible!
Thank you for contributing!
